# Getting Started with Alteryx

This section teaches new users how to use Alteryx step-by-step.

## 1. Install Alteryx Designer
Download the free trial from Alteryx.com and install it.

## 2. Learn the Interface
- Canvas (where workflows are built)
- Tool Palette (Input, Prep, Join, Transform, Reporting)
- Configuration Window (settings for each tool)
- Results Window (output preview)

## 3. Build Your First Workflow
1. Drag **Input Data** onto the canvas  
2. Select a CSV or Excel file  
3. Add **Data Cleansing**  
4. Add **Select**  
5. Add **Output Data**  
6. Click **Run**

## 4. Common Tools
- Input Data  
- Data Cleansing  
- Filter  
- Join  
- Summarize  
- Formula  
- Charting  
- Render

## 5. What You Can Build
- Automated KPI dashboards  
- Treasury metric reporting  
- Fundraising analytics  
- Customer segmentation  
- Trend analysis
